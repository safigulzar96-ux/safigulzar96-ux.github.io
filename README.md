# Safi Gulzar — Portfolio Website

A responsive, beginner-friendly portfolio website built with plain HTML, CSS, and JavaScript.

## Before publishing
1. Open `index.html` and confirm the project descriptions match what you have actually built.
2. Replace `YOUR_EMAIL@example.com` with your real contact email.
3. Add links to your real project repositories and screenshots when available.
4. Check that your GitHub profile URL is correct: `https://github.com/safigulzar96-ux`.
5. Do not claim skills, certificates, or project completion that you cannot demonstrate.

## Preview locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository named `safigulzar96-ux.github.io` if you want the site at `https://safigulzar96-ux.github.io`, or use any repository name for a project site.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. For a project repository: go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site. Use the exact URL shown in **Settings → Pages**.
5. Open the URL on your phone and computer to check it before putting it on an application.
